# Project Structure

This document explains the folder and file layout of the portfolio project so npm run developer or AI model can quickly understand where things live and how to modify them.

## Root Files

```text
my-profile/
  index.html
  package.json
  next.config.js
  eslint.config.js
  README.md
  ARCHITECTURE.md
  STRUCTURE.md
  public/
  pages/
  src/
  .next/
```

## Root File Responsibilities

| File | Purpose |
| --- | --- |
| `index.html` | Base HTML document, SEO metadata, socinpm start tags, structured data, analytics scripts, and React mount point. |
| `package.json` | Project metadata, dependencies, and npm/yarn scripts. |
| `next.config.js` | Next.js configuration for custom rewrites, redirects, and environment variables. |
| `eslint.config.js` | ESLint rules and JavaScript/React linting configuration. |
| `README.md` | Human-facing overview, setup instructions, and customization notes. |
| `ARCHITECTURE.md` | Explains rendering model, app flow, data flow, styling, SEO, and deployment architecture. |
| `STRUCTURE.md` | Explains project folders and file responsibilities. |

## Source Folder

```text
src/
  main.jsx
  App.jsx
  App.css
  index.scss
  assets/
  components/
  data/
  styles/
  lib/
middleware/
```

## Source File Responsibilities

| File | Purpose |
| --- | --- |
| `src/main.jsx` | React entry point. Mounts the app into the DOM. |
| `src/App.jsx` | Main app composition, theme state, AOS initialization, and footer/sidebar visibility logic. |
| `src/index.scss` | Global SCSS entry file imported by the app. |
| `src/App.css` | Legacy/default app stylesheet. Check usage before adding new styles here. |

## Components

```text
src/components/
  About.jsx
  Experience.jsx
  Footer.jsx
  Hero.jsx
  Projects.jsx
  Skills.jsx
  SocialSidebar.jsx
  Stats.jsx
```

| Component | Purpose |
| --- | --- |
| `About.jsx` | Professional summary section. |
| `Experience.jsx` | Work experience section. Currently uses a local array inside the file. |
| `Footer.jsx` | Footer, copyright text, and footer social links. |
| `Hero.jsx` | Main intro section with name, role, location, contact buttons, resume button, projects button, terminal card, and theme toggle. |
| `Projects.jsx` | Project grid with pagination controls. Reads project data from `src/data/projects.js`. |
| `Skills.jsx` | Skill groups and icons. Reads skill data from `src/data/skills.js`. |
| `SocialSidebar.jsx` | Floating social media sidebar. Reads social links from `src/data/socials.jsx`. |
| `Stats.jsx` | Quick portfolio metrics such as experience, projects, APIs, and uptime focus. |

## Data Files

```text
src/data/
  projects.js
  skills.js
  socials.jsx
```

| File | Purpose |
| --- | --- |
| `src/data/projects.js` | List of portfolio projects, descriptions, tags, and animation delays. |
| `src/data/skills.js` | Skill groups, skill names, and icon URLs. |

## Public Folder

```text
public/
  robots.txt
  sitemap.xml
  assets/
    images/
      site/
        android-chrome-192x192.png
        android-chrome-512x512.png
        apple-touch-icon.png
        favicon-16x16.png
        favicon-32x32.png
        favicon.ico
        site.webmanifest
```

| File | Purpose |
| --- | --- |
| `public/robots.txt` | Search crawler access rules and sitemap location. |
| `public/sitemap.xml` | XML sitemap for search engines. |
| `public/assets/images/site/` | Favicons, app icons, and web manifest assets. |

Files in `public/` are served directly from the site root. For example, `public/robots.txt` becomes `/robots.txt`.

## Build Output

```text
dist/
  index.html
  robots.txt
  sitemap.xml
  assets/
```

`dist/` is generated by `npm run build`. Do not manually edit files in `dist/` unless you are debugging build output. Source changes should be made in `src/`, `public/`, or root config files.

## Common Change Guide

| Task | Edit |
| --- | --- |
| Change name, role, location, contact buttons | `src/components/Hero.jsx` |
| Change about text | `src/components/About.jsx` |
| Change work experience | `src/components/Experience.jsx` |
| Add/edit projects | `src/data/projects.js` |
| Add/edit skills | `src/data/skills.js` |
| Change social links | `src/data/socials.jsx` |
| Change global colors/theme | `src/styles/_variables.scss` |
| Change page SEO title/description/schema | `index.html` |
| Change sitemap URL/date | `public/sitemap.xml` |
| Change crawler rules | `public/robots.txt` |
| Add resume download | Add `public/resume.pdf` |
| `Configure deployment` | `next.config.js` |

## Content Ownership

The current project mixes content in two places:

- Static data files: projects, skills, social links.
- Component files: hero text, about text, stats, and experience.

For better maintainability, future updates can move all portfolio content into `src/data/` and keep components focused only on rendering.

## AI Editing Notes

When an AI model modifies this project:

- Prefer small, focused changes.
- Do not edit `dist/` unless specifically asked.
- Keep React components simple and section-based.
- Keep styling in the matching SCSS file.
- Update `index.html`, `robots.txt`, and `sitemap.xml` when SEO-facing URLs change.
- Check whether deployment is at the domain root or a subpath before changing asset URLs.
- Preserve accessibility attributes such as `aria-label`, `alt`, and semantic headings.
